《怪物猎人 边境 ZZ》PC 单机版（MHFCN / MHZZ）的繁体中文文本数据。

游戏里的武器、防具、素材、道具共 **107,222** 条条目，其名称、说明与获取途径
整理为本仓库的 CSV，按游戏内的数据表分类组织。

数据可供汉化整合包作为文本来源，也适合译文校对、术语整理或其它工具读取。
游戏本体、启动器与构建好的补丁不在本仓库内。

## 数据格式

每个 CSV 共 **11 列**，UTF-8 编码：

| 列 | 说明 |
|---|---|
| `条目ID` | 游戏内条目标识，跨版本稳定，用于与上游项目对齐 |
| `游戏ID（十进制）` / `游戏ID（十六进制）` | `mhfdat.bin` 中的实际偏移标识 |
| `分类` | 游戏内的细分类（如「怪物素材」「装飾品」） |
| `当前名称` | 改动前的文本（旧汉化或原文） |
| `精翻名称（在此填写）` | **本次译文** |
| `当前说明` | 改动前的说明 |
| `精翻说明（在此填写）` | **本次译文**（`\n` 表示游戏内换行，`~C05` 等为内嵌颜色标记） |
| `当前获取途径` | 改动前的获取途径文本 |
| `精翻获取途径（在此填写）` | **本次译文** |
| `备注` | 译者备注，多为判定依据 |

「当前」与「精翻」成对出现，因此**任意两版 CSV 可直接 diff**，也能一眼看出改了什么。

> 字段里的 `~C05 … ~C00` 是游戏内文字颜色控制码，不是乱码；
> `≪…≫` 是客户端高亮标记，需原样保留。

## 翻译口径

游戏文本以 **CP932** 写入，字库是硬约束。

### 繁体正字为准

`對 / 卻 / 搖 / 獲 / 說 / 歷` 等保持正字，**禁止**被脚本自动换成日文新字形
（`対 / 却 / 揺 / 穫 / 説 / 歴`）。此类替换曾造成 334 处语义损伤，已全部回退。

### CP932 编不出的字必须改述

| 想用 | 实际采用 |
|---|---|
| 盔 | 兜 |
| 淚 / 溫 / 歷 / 歲 / 狀 / 戶 / 啟 | 涙 / 温 / 歴 / 歳 / 状 / 戸 / 啓 |
| 烤 | 燒 |
| 陷阱 | 罠 |
| 垃圾 / 醃 / 蜻蜓 / 靛 | 廢棄 / 漬 / 蜻蛉 / 藍 |

另有一批常用繁体字（`說 內 絕 貓 靈 輝 雞 狀 …`）在 CP932 中只有日文形，只能写日文形。

### 假名与英文名保留原文

约 4.6 万条假名装备名（`アメシスバイソンⅠ`、`ヴォトーⅡ`）缺少可靠对照，
音译会变成无法核对的名称，故保留；`Lethe`、`Zidoria` 等英文名同理。

### 损坏原文不改写

约 361 条被截断的名称（`レ Arma斯庫`）、约 19 条碎片化说明、碎纸片谜题等保留原样，
避免编造原意。

## 如何使用

- **做汉化整合包 / 打补丁**：按 `条目ID` 取 `精翻名称`、`精翻说明`、`精翻获取途径` 三列回填到 `mhfdat.bin` 对应槽位，空值表示沿用原文本。
- **校对译文**：直接看「当前」与「精翻」两列的差异。
- **查日文原文**：[`docs/日文原文对照.csv`](docs/日文原文对照.csv) 把每条的日文原文、当前文本与精翻并排列出，共 15.6 万行。
- **做词表 / 术语库**：见 [`docs/术语表与译名对照.md`](docs/术语表与译名对照.md)、[`docs/怪物名对照表.md`](docs/怪物名对照表.md) 与 [`docs/怪物素材物品对照表.csv`](docs/怪物素材物品对照表.csv)。

写回 `mhfdat.bin` 时需按 CP932 编码并对指针表重映射，这部分不属于本仓库范围。
