## 3. 需要说明的判定（含无法原样照抄术语的清单）

### 3.1 `オディバトラス` → **弩岩龍**（未采用题面「霸龍」）

- 题面术语表写 `オディバトラス → 霸龍`，同时注明「查梗时按 MHF 实际」。
- 游戏数据实证：`未分类:6140`「Odi Cannon Shell」的日文原名是 **弩岩竜の甲殻**；`未分类:6142`「Odi Gnashing Jaw」是 **弩岩竜の巨顎** —— `オディバトラス` 即「弩岩竜」。
- 而「霸龍」在本项目已是 **アカムトルム（覇竜）** 的定名（`未分类:11259` 覇竜の滅棘 → 霸龍滅棘，怪物名对照表第 51 行）。若把 オディバトラス 也叫「霸龍」，会与覇竜同名冲突。
- 故本批 `オディバトラス` 一律作 **弩岩龍**（書/甲殻/巨顎 3 条）。若坚持「霸龍」，只需改这 3 条。

### 3.2 `貓` 与 `黑` 无法编码，按 A 类规则换日文形

- 题面示例给的是 `闇貓團徽章・白`，但 `貓`(U+8C93)、`黑`(U+9ED1) 均**不在 cp932**（实测），而 `團`(U+5718) 可编码。
- 依硬性约束「A 类：黑→黒、貓→猫」，本批统一作 **`闇猫団徽章・白`**、`惡猫之追憶`、`黒芝麻茸` 等。
