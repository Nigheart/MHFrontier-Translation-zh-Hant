## 四、术语

- `パートニャー` → **隨從猫**（不用「隨從夥伴」）；`マイトレプーギー` → **我的訓練場豬**（沿用旧译的语义，统一定形）
- `ゼニー` → **澤尼**；`ＳＰ装備` → **ＳＰ裝備**（全角保留）；`Ｇ級` → **Ｇ級**（全角保留）
- `天廊武器専用` → **天廊武器專用**（`専` 是日文形，中文用 `專`；两者都在 cp932 内）
- 技能名按游戏内既有译名：`斬れ味`→斬味、`ガード性能`→防御性能、`聴覚保護`→聽覺保護、`溜め短縮`→縮短蓄力、`対防御ＤＯＷＮ`→對防御ＤＯＷＮ 等
- 四色珠：剣聖珠／双龍珠／剣王珠／刀神珠／鈍器獣珠／奏帝珠／天槍珠／砲皇珠／斬将珠／穿凰珠／銃仙珠／銃傑珠／弓鬼珠／磁星珠 → 劍聖珠／雙龍珠／劍王珠／刀神珠／鈍器獸珠／奏帝珠／天槍珠／砲皇珠／斬將珠／穿凰珠／銃仙珠／銃傑珠／弓鬼珠／磁星珠

## 五、旧译的主要问题

1. **术语漂移**：`パートニャー` 在旧译里出现「隨從夥伴／隨從猫」两套；`カナ` 音译与意译混用（`マイトレプーギー`→「我的訓練場豬服裝」／「我的小豬服」）。本轮统一。
2. **断行切断**：`透過精錬G級防具制作而成的裝／飾品。`、`能為天廊武器賦予新技能的秘石／。` 等，逐条改为语义断行。
3. **`値` 码位**：旧译混用 `值`（U+503C，cp932 无此字）；本轮全部为 `値`（U+5024）。
4. **9 条水龍部位说明混在 09 里**（`装饰品:14517–14525`），旧译有「支支巨大躯體」这类重复字错误，已重译。
