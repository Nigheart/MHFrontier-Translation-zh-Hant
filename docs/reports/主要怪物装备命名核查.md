## 1. 核查口徑與方法

### 1.1 判定規則（沿用專案既定規則）

1. **一律繁體**，與 CSV 現有風格一致。
2. **「繁形不在 CP932」時保留日文新字體形**（例：撃 徴 歩 縁 渇 郷 掲 渉 巣 晩 頬 涙 歴 録）。
   因此 `撃竜槍` → `撃龍槍`（不改意譯），`角龍射撃` 保留不動。
3. **不可用字表**（說 內 絕 擊 淚 溫 緣 黃 眾 歲 值 焰 每 你 吞 貓 靈 輝 鳩 窗 烤 陷 阱 褲 帕 卡 查 盔 產 吧 劃 跑 踩 繫 傢 糙 徵 仿 踢 渴 錄 剝 癮 醬 禱）：命中即改寫或保留日文字形（例 `焔天` 不改成「焰天」，改「炎天」）。
4. **日文漢字轉中文正字**：`竜→龍`、`剣→劍`、`亜→亞`、`黒→黑`、`鎚` 保留（CP932 可用）、`晩` 保留、`焔` 保留。
5. **改版後綴不動**：`Ｆ/ＦＺ/ＦＸ/Ｇ/ＧＦ/ＧＸ/ＨＣ/ＨＳ/ＧＳ/ＧＰ/ＺＰ/ＺＤ/ＺＸ/ＺＹ/ＺＦ/ＬＸ/ＲＸ/ＰＤ/ＳＰ/C/Ｄ` 一律原樣保留；`－改`、`・改` 保留原名寫法，不改成 `G`／`+`。
6. **【】結構必須保留**（全角，不用 `[]`）。
7. **長度校驗**：建議名 CP932 位元組長 ≤ 該行「當前名稱」長度（不以日文原名為上限，因多數行當前名已含 `211A・` 這類顯示前綴）。
8. **顯示前綴 `5E30・`／`211A・` 不視為名稱的一部分**，但若當前名有、精翻名無，屬資料一致性問題，單列（見 6.5）。

### 1.2 系列識別方法

以「日文系列名」為錨點，而不是中文名——因為中文名一旦錯譯，就再也找不到它。做法：
`日文原名 → 去掉部位詞（ヘルム/キャップ/メイル/…）→ 去掉改版後綴 → 得到系列基名`，
再與台服怪物表（[MHFZCN](https://mhwiki.axibug.com/MHFZCN/mons/_mons_n.htm)）對照，即得「日文系列名 ↔ 台服怪物名」對照。

本次共覆蓋 **65 個怪物系列、約 5,700 行**防具與武器。

### 3.1 套用方式（給實作參考）

對上述系列，最安全的做法是**只替換系列名前綴，保留改版後綴與部位詞**：

```
正則：^(現有錯名)(變體後綴)(部位詞)$  →  (正確系列名)\2\3
例：  托亞FX頭兜  →  凍王龍FX頭兜
      法爾科HS頭兜 →  極龍HS頭兜
      霞龍迪魯F     →  鋼龍迪魯F     ← 注意「迪魯」也是 ディール 的音譯，可一併改「鋼龍靴」等
      王后F鎧甲     →  炎王龍F鎧甲
```

⚠️ 但 `カイザー` 與 `エンプレス` 都改成「炎王龍」會撞名（男裝/女裝）。三個選項：
- A（建議）：統一「炎王龍」，靠男/女外觀區分——最貼近台服原名，但同表會出現同名不同 ID。
- B：`カイザー`→「炎王龍」、`エンプレス`→「炎妃龍」——**不建議**，語義錯（エンプレス是テオ不是ナナ）。
- C：`カイザー`→「炎王龍・王」、`エンプレス`→「炎王龍・后」——可區分但延長名稱。
**此項需用戶拍板**，其餘 P0 可直接套用。
