### 1.5 提取方法（已脚本化，全只读）

1. **ECD 解密**：头部 `ecd\x1a`，`index=u16@4`，`fsize=u32@8`，`crc32=u32@12`；用 `rndBufEcd` 表做 4-bit 混沌 XOR 解密。
2. **容器头**：`JKR\x1a`（或 `JPK\0`），`type=u16@6`（=3 为 LZ），`offset=u32@8`，`usize=u32@12`。
3. **LZ 解码**：JPK 变体 LZ，1 位标志 + 三种回溯匹配 + 长串直拷。
4. **文本读取**：说明/名称均为 **cp932**，NUL 结尾，指针表定位：
   - 防具名称 `u32@0x64/0x68/0x6c/0x70/0x74`，说明 `u32@0x78` 起每件 4 个 slot
   - 近战武器名称 `u32@0x88`，说明 `u32@0x8c`；远程 `u32@0x84/0x90`
   - 物品名称 `u32@0x100`，说明 `u32@0x12c+0x60`，获取途径 `u32@0xa40`
   - 计数表 `8×u16 @ u32(0xe8)`

**现成脚本**：`full_unpack.py`（解包）、`target_entry.py`（取单条）、`extract_jp_strings.py`（抽日文串）、`jp_desc_export.py`（导出残留日文说明）、`mhfdat_kana_inventory.py`（假名归属统计）。

已复现校验：原机翻解包 SHA256 = `689c351c…a7b8`，与工作区历史快照**完全一致**。

### 2.3 「薬品加工」原词确认

**日文原词就是「薬品加工」，不是别的词。** 证据：

1. 本机数据中「薬」只用过 **1 次**（`0x1c8cd1`「薬品加工。」），其余「薬」全部被转成了「藥」——说明这一条是**唯一被机翻跳过的日文原词**（汉日同形，MT 未转换）。
2. wiki 上 `ダークサイス`/`ダークトーメント` 说明末尾**逐字都是「薬品加工。」**。
3. 它是真实游戏机制术语，同站 [weapon30](https://mhwiki.axibug.com/mh_jpn/item/weapon30.htm) 有更完整表述：
   > 「ゴーレムブレイド最終強化版。**薬品加工でより斬れ味が上昇**。雌雄関係にある剣が存在する。」
   （ジークリンデ / ジークムント，素材含「鬼人薬グレート」）

   即：**用药品（鬼人药等）对武器加工，可提升斩味**。
4. 本机同机制译文佐证：
   - `0x1c8adc`「經藥品加工處理的骨刀。」
   - `0x1c8e4a`「經藥品加工斬味更上一層。」
   对应日文应为「薬品加工を施した骨刀。」「薬品加工で斬れ味が一段と向上。」

### 1. 本机有没有日文/英文原文？

**分三档，必须区分开：**

| 对象 | 有没有原文 | 位置 / 依据 |
|---|---|---|
| 任务、事件、系统提示文本 | **有，完整日文** | `mhf.bin`（94 条）、`mhf_90c.bin`（95 条），未加密明文 |
| 装备/物品**名称** | **大量日文残留** | `mhfdat.bin` 解包后的名字池（`ダークサイス`、`レウスグリーヴ`…） |
| 防具**说明** | **仅 75 条残留**，真正的句子约 10 组 | `mhfdat.bin` 解包，如 `東ヨリ日出ヅルクニヨリ千歳…` |
| **武器说明** | **没有** | 全部已被机翻成中文；`死神/両断/飛竜/薬品` 在 melee 表中 0 条日文命中 |
| **英文说明** | **没有** | 只有英文武器名，无英文句子 |

> 依据：全库关键词扫描「薬品」「死神」「両断」「飛竜」「大鎌」「ダーク」——`mhf.bin`/`mhf_90c.bin`/`result.bin` 中除「鎌」外**全部 0 命中**；`mhfdat` 中这些词只出现在**中文机翻结果**里。

**所以：本机不存在目标武器说明的日文原文；不存在任何英文装备说明原文。**

### 3. 「薬品加工」最合理的中文译法

**推荐：`药品加工。`**（简体）

理由：
- 日文原词即「薬品加工」，是**名词性机制标签**（一行独立标记），不是完整句子；
- 机制含义已被 wiki 确认：以药品（鬼人药等）加工武器、提升斩味；
- 保持「四字 + 句号」的原文节奏，与本机同机制句「經藥品加工斬味更上一層」用词统一。

**可选的更自然写法（视整段语境）：**

| 译法 | 适用场景 |
|---|---|
| **药品加工。** | 推荐。标签行，最忠实 |
| 经药品加工。 | 略冗，但读起来完整 |
| 以药品加工而成。 | 当作描述句时 |
| 药品强化加工。 | 若想让玩家一眼懂"是种强化" |

**不建议**译为「药物加工」「药剂加工」——MHF 体系内「薬品」固定对应游戏内素材大类「药品」，且本机已有「藥品加工」译法在用。

**整条说明建议定稿（繁体/简体按项目风格统一）：**

```
镰刀之形，一挥即断飞龙类的死神大镰。
药品加工。
```
（三行版：`镰刀之形，能将飞龙类一` / `刀两断的死神大镰。` / `药品加工。`）
