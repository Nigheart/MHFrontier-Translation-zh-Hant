## 一、结论摘要

1. **「盾甲」是 `甲殻` 的错误译法，全表 52 条**；更严重的是整个殻类**错位一档**：`甲殻→盾甲`、`堅殻→甲殼`、`殻→盾甲`。所以 `雌火龍盾甲` 应为 `雌火龍甲殼`，`火竜の堅殻` 的「雄火龍甲殼」应为 `雄火龍堅殼`。合计 81 条。
2. **等级词被替换成 `G`**：`上鱗→G`、`尖爪→爪G`、`鋭牙→上牙`、`剛爪→上質爪`。`火竜の上鱗` 现作「雄火龍G」，既不忠于原文，又会和 G 级装备混淆。合计 122 条。
3. **怪物名成批串号**：`蛮竜`（グレンゼブル）被按英文 "Guren" 译成「紅蓮」14 条；`蒼火竜` 出现「A火龍／S火龍」；`桜火竜` 出现「P.火龍／P.雌火龍」；`古龍種` 被译成「長老龍王」33 条（Elder Dragon 的 elder 被当成「长老」）；`多殻蟹` 素材全写成「鎌蟹」；`大巌竜` 写成「老山龍」；`巨大貝の殻` 写成「創音龍盾甲」。
4. **格式主流是不加助词**：无「的／之」778 条（87.7%）、带「之」104 条、带「的」5 条。建议统一为 `{怪物名}{部位词}`，不加「的／之」。
5. **CP932 实测**：`銳 絕 軀 焰 狞 吞` 均**不可编码**，必须写 `鋭 絶 躯 焔 獰 呑`。部分条目被改写成「上牙／強力」很可能就是因为这几个字打不出来——这属于用字倒逼的误译，必须回改。
6. **狞龙（アビオルグ＝獰竜）的素材根本不在 08 表**，而在 `10_未分类物品与素材.csv`（48 条），现译名**四种混用**：阿比／阿比奧魯古／冰狐龍／吉奥。建议统一为 `獰龍`，亚种 `冰獰龍`。
7. **装备同理**：`アビオ`（60 件）、`アビG/GF/GX`（24 件）、`サベージ`（30 件）、珠（28 件）现分写「阿比奥魯古／阿比／冰狐龍／阿比BM」。注意 `アビット`（阿比托）是**另一套活动装**，千万不要跟着改成獰龍。

## 二、核查口径与方法

1. **对齐**：`游戏ID（十进制）` == `mhf_items_name_ja_en.csv` 的 `index`。887 条怪物素材**全部命中**日文原名（脚本 `_audit_materials.py`）。
2. **拆分**：按 `{種名}の{部位詞}` 拆开，共 380 种部位词、近百个種名前缀。
3. **生成建议名**：`{怪物中文名}` + `{部位词}`（不加助词），逐条做 CP932 校验；不可编码的方案会被自动丢弃并人工改写。
4. **差异分桶**（887 条）：

| 类别 | 条数 | 说明 |
|---|---|---|
| 与日文原名一致 | 136 | 仅「之／的」差异也算一致 |
| 无「の」结构，规则不适用 | 66 | 如 `竜骨【小】`、`なぞの骨`、`生産券` |
| 部位词生僻／专名，无法比对 | 45 | 如 `ザザミソ`、`モノブロスハート` |
| **殻类错位** | **81** | 规则级 |
| **等级词丢失** | **123** | 规则级 |
| **怪物名／前缀错** | **196** | 规则级 |
| **部位词误译** | **234** | 其中 7 条复核可接受，列单 227 |
| **符号／全角** | **6** | |
| 合计 | **887** | |

> 上表「部位词误译 234」里有 7 条经人工复核判定**可接受**（`魔物糞便`、`飛龍涙水`、`炎妃龍鱗` 这类），未列入清单；另在「无法比对」的 45 条中人工检出 **16 条真错**，列在 4.6。因此**清单合计 649 条**（81+123+196+227+6+16）。

> 注：196 条「怪物名错」里也包括「黑色鎧龍」「白色棘龍」这类**多加颜色词**、`黒`/`黑` 混用、`祖龍` 写成「白色黑龍」等前缀问题，不全是大错，但都需要统一到種名。

## 三、命名规范建议

### 3.1 拼接格式

| 写法 | 条数 | 占比 |
|---|---|---|
| `雄火龍鱗`（不加助词） | 778 | 87.7% |
| `雄火龍之翼`（加「之」） | 104 | 11.7% |
| `眠鳥的金赤毛`（加「的」） | 5 | 0.6% |

**建议：统一 `{怪物名}{部位词}`，去掉「的／之」。** 理由：①多数已经是这种写法；②「之」偏文言，和装备、道具表的语体不一致；③名字越长越要省字（`蒼雄火龍之翼` → `蒼雄火龍翼`）。
唯一例外：`竜骨【小】` 这类非「種名＋部位」结构的专名，不要硬套。

### 4.2 等级词丢失（123 条）

规则：`上X→上X`（不是「XG」）、`尖X→尖X`（不是「XG」）、`剛X→剛X`（不是「上質X」）、`鋭X→鋭X`（不是「上牙」）。
最典型：`火竜の上鱗` 现「雄火龍G」→ **雄火龍上鱗**；`飛竜種の剛爪` 现「飛龍種上質爪」→ **飛龍種剛爪**；`轟竜の鋭牙` 现「轟龍上牙」→ **轟龍鋭牙**（「上牙」在中文里是上排牙齿，歧义严重）。
另：`真肝／重顎／秘涙` 被写成「肝GG／顎GG／涙GG」，双 G 更是无解，应作 `真肝／重顎／秘涙`。

### 5.4 三个坑（务必避开）

1. **`アビット`（Abitto／阿比托）不是狞龙**。它是活动装系列（`アビットヘッド／Ｆヘッド／ハール`…，共 30 件防具 + `アビット生産券` 5 张），日文读音和 `アビオ` 只差一个音。**保持「阿比托」不动**，不要做全局替换。
2. **`アビサル`（Abyssal）也不是**。`アビサルFU生産券`、`アビスランツェSP`、`アビサルフューリー` 都是别的系列（现译「阿比薩魯」），一样别动。
3. **`アビ剣珠` 的英文是 `Abi BM`**，不是「Abiorugu BM」。改中文时按 `獰龍劍珠` 走，但**不要**把英文侧当成依据去改成「Abiorugu 珠」——那是缩写，不是种名。

另外：`wpn_melee_name.csv`（17568 条）、`wpn_ranged_name.csv`（4223 条）里**没有** `アビオ*／獰*` 武器名，狞龙是否存在专属武器系列**无法确认**，需另查（可能是该怪本就没有武器派生）。

## 六、落地建议与风险

1. **分批**：P0 先改「殻类 81 + 怪名 196 + 符号 6」共 283 条（都是看一眼就对的机械替换）；P1 改「等级词 122」；P2 再处理「部位词 225」。
2. **必须全表去重**：MHF 的素材检索、素材箱、装备强化界面都按名字匹配。`盾甲`/`甲殼` 这种错位恰好让名字**互不相同**，一旦改对就会出现同名（例如各怪的 `堅殻` 都变成 `X堅殼`，同族不同怪仍不同名，问题不大；但 `古龍種` 34 条会全部收拢到同一个前缀，需要注意是否与其他条目撞名）。建议改完跑一次 `名称重复` 检查。
3. **狞龙必须跨表同步**：素材在 `10`，防具在 `01-05`，珠在 `09`。只改一处会出现「素材叫獰龍、装备叫阿比奥魯古」的更糟状态。
4. **`之`/`的` 不要顺手批量删**：`之` 出现 104 次，批量删会影响说明文本里正常引用。只改名称列。
5. **`黒`/`黑` 先定一个**：现档两种都有（`黒龍角` vs `黑龍盾甲`），两个字都能编码，建议统一用 `黑`（与术语表「黑龍」一致）。
