## 四、口径（1,502 + 640 组验证通过，逐条照抄）

1. **行数硬约束**：译文行数 = 日文 `{j}` 数 + 1。一条都不能变。
2. **按语义重排、不在词中切**：不出现「頭部裝 / 備。」「機能 / 方面」这类残片。
3. **宽度跟日文该行比**（`_a_base.check` 已实现）：
   - 译文 `> 14.5` 全角，**仅当日文该行 ≤14.5** 才报 `WIDE`；日文本身 15–19 宽的长标签放行。
   - 译文 `< 8`，**仅当日文该行 ≥8** 才报 `NARROW`；日文本身只有 `装備。`（5 宽）的行可照短写，**不要注水凑字**。
   - 译文 `< 5` 同理（`TINY`）。`~Cnn` 不计宽。
4. **控制标记**：`{cNN}…{/c}` → `~CNN…~C00`，序列与数量与日文逐条一致。
   统计时用 `~C(?!00)(\d\d)`（`~C00` 是结束符，不是色号）。
5. **`≪…≫` 跟随日文断行**（原版设计，320 处跨行）：
   - 允许跨行，但**逐行累计断点数必须与日文完全一致**（`LL-SPLIT`），且 `≫` 不能先于 `≪`（`LL-ORDER`）。
   - 三种切点都见过：`≪遷悠防具：⏎`、`≪遷悠⏎防具：`、`≪遷悠防⏎具：`，**照日文切**。
   - 标签类保持全角原样：`≪狩護防具≫`/`≪Ｇ級狩護≫`/`≪剛種防具≫`/`≪天嵐防具≫`/`≪覇種防具≫`/`≪Ｇ級覇種≫`/`≪烈種防具≫`/`≪始種防具≫`/`≪辿異防具≫`/`≪辿異狩護≫`/`≪天廊防具≫`/`≪ＨＣ防具≫`/`≪遷悠防具：…≫`/`ＳＰ防具：色`。
   - 剧情类中文化：`≪勝ち組≫`→`≪勝組≫`、`≪料理は真心≫`→`≪料理是真心≫`、`≪料理は度胸≫`→`≪料理是胆量≫`、`《絆は永久に》`→`《羈絆永久》`、`“闇の貴公子”`→`“暗之貴公子”`、`“夜の女王”`→`“夜之女王”`、`「キラービー」`→`「殺人蜂」`。
   - **「遷悠防具」的技能名不要压缩**，`雷属性攻撃【大】`／`状態異常攻撃強化`／`貫通弾・貫通矢威力UP` 全部原样保留（`属性`/`状態`/`弾` 用日文形）。
6. **行尾标点**：句中标点一律 `，`。行尾出现 `、` 会报 `TAIL-PUNCT`；`：` 只在 `≪…≫` 内部断行时允许。
7. **编码**：cp932 可编码且不落 NEC 区（`0xEB–0xFC` 双字节首）。
   繁体「裝/頭/部/龍/體/備」可用；日文新字形优先：`黒 絶 内 説 産 撃 増 緑 悦 頼 歴 徴 歩 毎 髪 芸 蝋`。

## 八、已知坑（补充）

- **`_a_base.check` 的 `verbose=True` 会在 GBK 控制台崩溃**，用 `verbose=False` 自己打印。
- **组号是部位内的 1-based 序号**，不是条目 id。`_a_dump2.py` 输出里的 `G1234` 就是组号。
- 部分条目日文第 2 行是空的（`A。{j}{j}{c11}…`），译文不能出空行，需把句子重切成 N 行。
- 珠子说明类短条目（`分解時、怪力珠{j}装飾品装着は通常のみ`）按字面译，勿补上下文。
- 日文原文中出现 `~C0` 等残留标记（如 G971/body）不影响校验，只比对 `{cNN}`。
- `SP防具：色` 行整行是标签，宽度 6–7，别当成正文去凑字数。
- 某些组日文原文把 `≪≫` 劈在词中间（`≪遷悠⏎防具：`），译文也照劈，不要自作聪明重组。
