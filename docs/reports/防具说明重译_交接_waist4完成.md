## 五、⚠️ 字表修正（本任与父 agent 共同确认，**重要**）

父 agent 的物品组 A/B 表混了三类东西，只有第 1 类能脚本批量替换：

```
【第 1 类·纯字形差异，可安全批量替换】
增→増 值→値 黑→黒 內→内 擊→撃 銳→鋭 溫→温 說→説 歷→歴
步→歩 脫→脱 搖→揺 貓→猫 產→産 絕→絶 眾→衆 韌→靭 狀→状 每→毎

【第 2 类·换字，语义不同，必须人工选词】
獲→穫（獲得≠收穫）  賣→販  寬→廣  繫→連

【第 3 类·本来就可编码，不该进表】
對 U+5C0D ✓  誘 ✓  鋪 ✓
```

**结论：`_a_chk.py` 保持不动，不加自动替换。** 理由：校验器只该「报」不该「改」；
静默替换会让源文本里的简体形永远看不见，长期形成两套写法混用。
源头预检（写前 `enc_ok` 查可疑字）+ chk 0 错误，两条腿走路。
