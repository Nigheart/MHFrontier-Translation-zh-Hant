## 口径（1,040 组验证通过）

1. **行数硬约束**：译文行数 = 日文 `{j}` + 1 = 旧 `desc` 行数（43,451 条 0 例外）。
2. **按语义重排**：每行一个完整意思单元，**不在词中间断开**（不出现「頭部裝 / 備。」「機能 / 方面」）。末行允许短（≥5 字），中间行 8–14 全角。
3. **宽度上限 14**：日文原文本身存在 14 全角行（`熱血！大噴火！！{c11}≪ＨＣ防具≫{/c}` = 8+6），故阈值是 `> 14.5` 才报错。`~Cnn` 不计宽。
4. **控制标记**：`{cNN}…{/c}` → `~CNN…~C00`，序列与数量逐条与日文比对。`~C00` 是结束符，统计时须用 `~C(?!00)(\d\d)`。
5. **≪≫**：全角保留，内容译中文。标签类（`≪ＨＣ防具≫`/`≪狩護防具≫`/`≪Ｇ級狩護≫`/`≪剛種防具≫`/`≪天嵐防具≫`/`≪覇種防具≫`/`≪Ｇ級覇種≫`/`≪烈種防具≫`）原样；剧情类中文化（`≪料理は真心≫`→`≪料理是真心≫`、`≪勝ち組≫`→`≪勝組≫`）。`《絆は永久に》`→`《羈絆永久》`、`“闇の貴公子”`→`“暗之貴公子”`、`「キラービー」`→`「殺人蜂」`。
6. **编码**：只排除 cp932 `0xEB–0xFC`（NEC 区）。繁体「裝/頭/部/龍/體」**可用**；真正不可用的是简体字或异体字，见下表。

## 注意事项

- `id` 形如 `头部防具:21`，`file` 形如 `01_防具_头部.csv`；按 `file` 分部位比按 id 前缀更稳。
- 部分条目日文第 2 行是空的（`A。{j}{j}{c11}…`），译文不能出空行，需把句子重新切成 N 段。
- 短条目（`分解時、怪力珠{j}装飾品装着は通常のみ`）是珠子说明，按字面译，不要补上下文。
