## 12. 校验编码规则（最终版，已取代此前两版）

此前先用了 `cp932`（太宽松），又一度改成 `shift_jis`（太严格，误杀罗马数字），
**最终规则**为：

```python
def enc_ok(s):
    b = s.encode('cp932')                 # ① 先保证能编码
    i = 0
    while i < len(b):                     # ② 逐双字节字符检查首字节
        c = b[i]
        if 0x81 <= c <= 0x9F or 0xE0 <= c <= 0xFC:
            if 0xEB <= c <= 0xFC:         # NEC 扩展区 -> 拒绝
                return False
            i += 2
        else:
            i += 1
    return True
```

**判据：NEC 扩展区的「汉字」拒绝，NEC 扩展区的「符号」放行。**

| 字符 | cp932 字节 | 首字节 | 判定 |
|---|---|---|---|
| `黒` U+9ED2 | 8d95 | 0x8D | ✓ 标准区 |
| `黒`/`黑` U+9ED1 | eeec | 0xEE | ✗ NEC 汉字 |
| `德` U+5FB7 | ed9e | 0xED | ✗ NEC 汉字 |
| `綠` U+7DA0 | ee70 | 0xEE | ✗ NEC 汉字 |
| `Ⅰ` U+2160 | 8754 | 0x87 | ✓ NEC 符号，**放行** |

### 关于罗马数字（重要，勿再改）
