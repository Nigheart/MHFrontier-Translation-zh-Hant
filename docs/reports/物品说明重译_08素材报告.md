# 08 素材（物品/素材说明）重译报告

> 范围：`_retrans_item.json` 中 `08_素材_怪物生物矿石.csv` 的 **1,074 条**（怪物素材 887 / 生物素材 106 / 矿石 81）。
> 产物：`item_retrans.json`（幂等键 = 条目ID）。

## 一、口径与依据

### 1. 行数口径（重要，与任务书原始假设不同）

任务书假定「08/09 是多指针，行数必须严格匹配；10/11 是单指针，行数自由」。核对回填清单后**该假设不成立**：

```
回填定位_请保留.jsonl.gz → 每个条目的 description 槽数
怪物素材 1 / 生物素材 1 / 矿石 1 / 装饰品 1 / 未分类 1 / 其他物品 1 …
头部防具 4 / 身体防具 4 / 腕部防具 4 / 腰部防具 4 / 脚部防具 4 / 近战武器 4 / 远程武器 4
```

即 **16,686 条物品类说明 100% 是「1 个说明指针」**（`backfill.py` 的 `set_description()` 走单指针分支，整串含 `\n` 直接写入），只有防具/武器是 4 槽。

因此对物品而言行数不是结构性约束。本轮仍**按日文行数产出**（保持与原文相同的版面、行数与断行位置），仅 4 条因中文短于日文而并行（见第四节 note）。

### 2. 输入里的分隔符

`jp_desc` 里是**真换行 `\n`**（不是 `{j}`）；`desc` 里是**字面 `\n`**。本轮输出沿用 `desc` 的表示法（字面 `\n`）。

### 3. 断行原则

- 每行是一个完整语义单元，断在句读/从句之间，不在词中间断开；
- 行首不出现 `的／了／著／且／之／備／裝／，／。` 等残片（旧机翻的典型病症，如 `頭部裝 ⏎ 備。`）；
- 与日文原文逐行对应（同一句落在同一行），不跨行合并语义。

### 4. 行宽

- 目标 **9–13 全角**（`~Cnn`、`≪≫` 不计宽），实测 2,065/3,069 行落在 9–13；
- 其余 1,004 行偏短，**几乎全部是日文该行本身就短**（如 `魔物の糞便。`＝6、`かなり濃厚。`＝6、`XX之皮。`）。物品名在中文里比片假名怪名短 3–4 字，强行凑到 9 字必然要加原文没有的字。因此对「日文该行 < 9 字」的行按实际长度处理。

### 5. 控制标记

- `{c05}…{/c}` → `~C05（…）~C00`，色号与顺序与原文逐条比对通过；
- `{c05}（旧称：…）` 系列保留「舊稱」格式并补 `~C00`；
- `≪…≫` 保留全角且不跨行（`【けんかく】` 一类读法注记按项目惯例转 `≪…≫`）。

### 6. 用字

按 cp932 实测做归并：`內→内 擊→撃 銳→鋭 溫→温 增→増 絕→絶 說→説 歷→歴 殼/殻→殼 韌→靭 脫→脱 搖→揺` 等；禁用 `值(U+503C)` 改用 `値(U+5024)`（`稀有价值`→`稀有価値` 一处已修）。全表 0 条不可编码。

## 五、旧机翻的典型错误（本轮已修）

1. **按字节硬切**：`帶著鷄冠的巨大頭部。戴上後有 / 種藍速龍感` → 断在「有／種」之间；本轮重排为语义行。
2. **行首残片**：`的汁。`、`備。`、`之熱的強度。` 等 200+ 处，全部消除。
3. **怪名张冠李戴**：`怪物素材:364 怪鳥甲殼` 旧译「毒怪鳥的耐火性甲殼」（イャンクック 误作 ゲリョス）；`441 黒鎧龍甲殼` 旧译「黒色岩龍甲殼」（グラビモス 误作 バサルモス）；`111 雄火龍甲殼` 旧译整条错成「蒼色雄火龍之鱗」（与 JP 不符）；`374 橡膠質皮` 旧译「毒怪鳥」正确但 `63/66` 混用。已按 JP 逐条校正。
4. **装饰性误译**：`638 盾蟹斷爪` 旧译「而稱【斷裝】」（【ダンソウ】误作「斷裝」），改为「【斷爪】」。
5. **空指针内容**：`673 煤石礦石` / `674 石英礦石` 旧译是「任務用≪納品物≫，不可帶回。」（根本不是说明），已按 `灰水晶を含有する原石。` 重译。
