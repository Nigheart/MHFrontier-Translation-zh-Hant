## 四、字形黑名单（累积，最重要的坑）

cp932 有些字**繁体形编不出，反而日文新字形可以**。这是全程最高频的错误来源。

### A 类：纯字形差异，可安全批量替换
```
增→増  值→値  黑→黒  內→内  擊→撃  銳→鋭  溫→温  說→説  歷→歴
步→歩  脫→脱  搖→揺  貓→猫  產→産  絕→絶  眾→衆  韌→靭  狀→状  每→毎
鍊→錬  閒→閑  軀→躯  徵→徴  歲→歳  悅→悦  渴→渇  妒→妬
```

**最容易踩、必须记住的三对：**
```
說(U+8AAA) ✗ → 説(U+8AAC) ✓      ← 「據説」不是「據說」
貓(U+8C93) ✗ → 猫(U+732B) ✓      ← 「艾露猫」不是「艾露貓」
腳(U+8173) ✗ → 脚(U+811A) ✓      ← legs 部位词全靠这个
```

### B 类：cp932 完全编不出，必须改述
```
舔 嚐 份 拼 傢伙 烤 迷你 牠 你 暱 撑 擰 盯 緣 咕 嘟
辦 污 糕 蠟 盔 卡 啪 麵 朵 獷 佔 蟬 懂 桅
她 哪 喻 檔 搞 吧 阱 焰 祈 鬃 骷髏 繫 藴 瞄 沉 癮 扭 仿
產(混用) 查
跑 澈 晚 盼 均(勻) 醞 憑 擋 屠(可用) 邁(可用)
嫉妒→嫉妬  豔/艶 均不可靠 → 用「妖魅」
```
改述方案见前几任交接文档第六节表格，本任延续使用，例如：
`祈禱→祝願`、`陷阱→圈套`、`搭檔→夥伴`、`沉→沈/潛藏`、`喻→比擬`、`澈→淨`。
