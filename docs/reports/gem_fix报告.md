## 4. 不可编码字处理（硬性约束）

原字 → 替代字（均为 cp932 标准区可用字，避免 NEC 区 0xEB–0xFC）：

| 原字 | 替代 | 原因 |
|---|---|---|
| 黑 U+9ED1 | **黒** U+9ED2 | 原字落 NEC 区 |
| 綠 U+7DA0 | **緑** U+7DD1 | cp932 无定义 |
| 擊 U+64CA | **撃** U+6483 | cp932 无定义 |
| 狀 U+72C0 | **状** U+72B6 | cp932 无定义 |
| 絕 U+7D55 | **絶** U+7D56 | cp932 无定义 |
| 囊 U+56CA | **嚢** U+56A2 | cp932 无定义（按用户确认用 `嚢`） |
| 烤 U+70E4 | **燒** U+71D2 | B 类不可编码字 |
| 貓 U+8C93 | **猫** U+732B | cp932 无定义 |
| 查 U+67E5 | **査** U+67FA | cp932 无定义 |
| 黃 U+9EC3 | **黄** U+9EC4 | cp932 无定义 |
| 虛 U+865B | **虚** U+865A | cp932 无定义 |

> 原数据中已有 73 条含不可编码字（`黑` 67、`綠` 6），本次已全部落入修复范围。
