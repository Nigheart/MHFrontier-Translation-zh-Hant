## 二、高频模式的判断结论

### 1) 火龍 → 雌火龍 149 条：**全部「原文如此」，不改；不是名称错也不是说明错**

真因是**脚本提取器的假阳性**，与译文无关：

| 构件 | 日文名称 | 日文说明 | 说明中的怪 |
|---|---|---|---|
| リオデュオ（火龍雙子）70 条 | リオデュオ… | ”天”を統べる**雄火竜**と”地”を揺るがす**雌火竜**の魂… | 雄＋雌**两只** |
| リアルオ／レウアス／レイレス 72 条 | リアルオ…等 | 天に舞う**雄火竜**と地を轟かす**雌火竜**… | 雄＋雌**两只** |
| リオハート（火龍之心）7 条 | リオハート… | **桜火竜**の素材／桃色の**雌火竜**／**リオレイア**… | 雌系 |

- 名称「火龍雙子兜／雄火龍G鎧甲／火龍之心G兜」只含「火龍」；说明同时写「雄火龍」+「雌火龍」，`find()` 把「火龍」判给了更长的「雌火龍」，于是报「名称火龍 vs 说明雌火龍」。
- 中文说明「統御”天”的雄火龍與震撼”地”的雌火龍之魂」是**逐字照译**，完全正确。
- リオハート／リオソウル 两条：日文名（リオ＋ハート／ソウル＝火龍之心／魂）与日文说明（桜火竜／蒼火竜）**在原文里就不同称**，照译即正确。

### 2) 尾晶蠍 → 灰晶蠍 80 条：**名称错**（说明对）

```
头部防具:547  JP名 アクラＵヘルム
              JP说 灰晶蠍の分厚い殻を加工して作られた頭装備。仕上がりの色は素材次第。
              CN名 尾晶蠍U兜        ← 错
              CN说 將灰晶蠍厚殼加工製成的頭部裝備。成品色澤取決於素材。  ← 对
```

`アクラ` 是 アクラ・ジェビア（尾晶蠍）与 アクラ・ヴァシム（灰晶蠍）的共同前缀；日文说明一律写「灰晶蠍」→ 该系列属 **アクラ・ヴァシム＝灰晶蠍**。名称却取了另一只「尾晶蠍」。
→ 80 条 `name`：`尾晶蠍U兜 → 灰晶蠍U兜`（U/R 各部位同）

### 3) 電龍 → 芙芙爾 65 条：**说明错**（名称对）

```
头部防具:27   JP名 フルフルヘルム            CN名 電龍兜          ← 对
              JP说 フルフルの皮で覆われた…   CN说 被芙芙爾皮覆蓋的…  ← 错
头部防具:7601 JP名 フルンＧヘルム            CN名 紅電龍G兜       ← 对
              JP说 フルフル亜種の素材を活かした… CN说 活用芙芙爾亞種素材的… ← 错
```

`芙芙爾` 是 フルフル 的音译（非项目定名）；`フルフル亜種` 应作「紅電龍」。
- 47 条 `desc`：`芙芙爾 → 電龍`
- 18 条 `desc`：`芙芙爾亞種 → 紅電龍`

### 4) 角龍 → 一角龍 57 条：55 条**名称错**

```
头部防具:109  JP名 モノデビルヘルム
              JP说 モノブロスの角が見るものを畏怖させる…（モノブロス＝一角龍）
              CN名 黒角龍兜   ← 错（黒角龍＝ディアブロス亜種，另一只怪）
              CN说 一角龍之角令見者畏懼…  ← 对
```

- 另 2 条（デスブロスサイス、角龍之牙）日文本身用「ブロス／角竜類」泛称，不改

### 5) 鎌蟹 → 將軍鎌蟹 51 条：**同一怪简称／全称，不算错**

日文名用简称「ギザミ」、日文说明用全称「ショウグンギザミ」；中文名称「鎌蟹」对应简称、说明「將軍鎌蟹」对应全称，两者都对。
