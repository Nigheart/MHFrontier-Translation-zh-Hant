## 四、使用提示

1. **竜 / 龍**：日文原作一律「竜」，繁中官方作「龍」，简中作「龙」。
2. **MHF 与官方繁中的差异**：MHF 台服沿用旧译（火龍、金獅子、將軍蟹、蛇龍、飛甲蟲），与 MHW/MHRise 的官方译名不完全一致，批量替换时不要全局套用。
3. **CP932 限制**（MHF 客户端编码）：可用「龍、鱗、殼、寶、紅」，不可用「盔、淚、溫、歷、歲、狀、戶、啟、為、烤、陷阱」等；本表中若出现这些字，导入前需替换（如「陷阱」→「罠」、「烤」→「燒」）。
4. **投射器弹**：MHW 的「投射器闪光弹 / 音爆弹 / 异臭弹」在 MHF 中对应「閃光玉→閃光彈 / 音爆彈 / 糞炸彈」，名称不是一对一直译。
5. **稀有素材**：`Plate` = 逆鱗、`Gem` = 寶玉、`Ruby` = 紅玉、`Mantle` = 天鱗（原文分别写作 逆鱗 / 宝玉 / 紅玉 / 天鱗），英文不看字面义。
