## 六、异体字规范（重要）

**项目标准：中文正文用繁体正字，遷悠技能名照抄日文新字形。**

| 场景 | 用字 |
|---|---|
| 中文正文 | 對 卻 搖 獲 說 歷 讚 圖 劍 疊 臟 樂 勞 |
| 遷悠技能名 | 広域化 属性攻撃 貫通弾（日文形） |
| NEC 区字（须换） | 黑→黒 絕→絶 內→内 增加→増加 價值→價値 綠→緑 說→説 歷→歴 |
| 日文新字形（可用） | 裝 頭 部 龍 體 備 胸 腕 腰 脚 繫 説 産 撃 涙 |

> **历史教训**：曾有批次把 `獲→穫`、`對→対`、`卻→却`、`搖→揺` 当成"字形统一"批量替换，造成 334 处语义损伤（`獲得→穫得`）。**可编码的字不要动。**

## 七、CP932 字符限制（三类）

### A 类：源字在 NEC 区，换成日文形（可脚本替换）

```
增→増  值→値  黑→黒  絕→絶  內→内  擊→撃  銳→鋭  溫→温
說→説  歷→歴  步→歩  脫→脱  搖→揺  貓→猫  產→産  眾→衆  勞→労
綠→緑  悅→悦  賴→頼  菇→茸  寬→寛  橫→横  閒→間  薰→薫
```

### B 类：cp932 完全编不出，必须改述

```
舔 嚐 份 拼 傢伙 烤 迷你 牠 你 暱 撑 擰 盯 緣 咕 嘟
辦 污 糕 蠟 盔 卡 啪 麵 朵 獷 佔 蟬 懂 桅 巢
```

替代示例：
```
烤 → 焼      迷你 → 小型     牠 → 貓/牠(改写)
暱稱 → 小名   支撑 → 支持     擰 → 擠
盯着看 → 一直看  粗獷 → 粗野    蜂巢 → 蜂窩
```

### C 类：源字可用，**禁止自动替换**

```
對 卻 搖 獲 讚 圖 劍 疊 臟 樂 勞 賣 寬 繫
```
